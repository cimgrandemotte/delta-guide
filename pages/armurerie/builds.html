Comment importer

Dans le jeu : Armurerie (Armory) > sélectionner l'arme > Modifier > Loadout > Importer un code. Coller la chaîne complète, nom de l'arme inclus.

⚠
Un code est lié à une version du jeu et à une région (Global vs Garena). Un code peut cesser de fonctionner après un patch majeur.

Loadouts types

Budget Brakkesh Extract

Faible
  • Casque DICH violet endommagé (+50% portée auditive)
  • Gilet violet
  • SMG bon marché à cadence élevée
  • Munitions violettes (niveau 4)
  • Opérateur : Hackclaw

Objectif : Sortir en vie avec du loot plutôt que gagner des duels. Foncer vers Babel, extraire par la dog tag extraction.

Faction Run Brakkesh

Minimal
  • Chest rig bleu
  • Casque bleu
  • Sac bleu
  • Pistolet uniquement
  • Objet de mission dans la Safe Box

Objectif : Monter le Faction Badge sans rien risquer. La Safe Box survit à la mort.

Boss Hunt Tide Prison

Élevé
  • M4A1 (DPS)
  • ASh-12 (casse-armure, Ops Lv.40+)
  • S12K (phase rapprochée)
  • Munitions niveau 5
  • Kits de réparation d'armure
  • Soins en quantité

Objectif : Abattre Warden Ghroth et extraire la Ghroth Judgement Card... qui n'est PAS extractible : l'utiliser en match.

AZ3 Elite Run

Très élevé
  • Entrée 112 500 Alloys
  • Decontamination Chamber améliorée
  • Munitions niveau 5
  • Armure niveau 5+

Objectif : Rentabiliser le ticket d'entrée : viser les salles à forte valeur, extraire tôt.
